# Experiment 4: Calendar-Based Post Scheduling

## Aim

To enhance the existing Post Composer application by implementing a calendar-based interface for scheduling and managing posts.

## Objectives

* To implement a calendar-based scheduling interface.
* To display scheduled posts according to date and time.
* To allow users to create and manage scheduled posts.
* To provide an interactive interface for post scheduling.
* To integrate the calendar with the existing Post Composer.

## Technologies Used

### Frontend

* React.js
* React Router
* Axios
* JavaScript
* CSS

### Backend

* Node.js
* Express.js

### Database

* MongoDB Atlas
* Mongoose

## About the Program

This experiment adds **calendar-based post scheduling** to the existing Post Composer application.

Users can schedule posts for a specific date and time. Scheduled posts are displayed on a calendar, allowing users to easily view and manage their planned posts.

## Features Added

* Calendar View
* Schedule Post by Date and Time
* View Scheduled Posts
* Edit Scheduled Posts
* Delete Scheduled Posts
* Manage Post Schedules


## Expected Outcome

A functional calendar-based scheduling system is integrated with the existing Post Composer, allowing users to visually manage their scheduled posts.

## Learning Outcomes

* Understand calendar-based UI design.
* Work with date and time in React.
* Implement post scheduling.
* Map posts to calendar events.
* Integrate calendar functionality with a MERN application.
